## English

Hi Stefan,

BumpMesh gave me the idea to build something like it right into my print-file library. The
result is **Texgrove**, a plugin for Meshgrove (both open source): textures as real geometry on
models from the library, with the results landing beside the originals.

Texgrove is written from scratch in Rust. I took neither code nor textures from BumpMesh; the
README and the plugin's info name BumpMesh as the inspiration, with a link.

If anything about that mention bothers you, or you would like it worded differently, just tell me.

Thanks for BumpMesh, and best regards
Davis (German Redneck Engineering)
